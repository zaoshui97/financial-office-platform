## 【附录：亮点技术细节（方便你后期落实）】

### 亮点一 · 枢会智联

| 技术模块 | 实现方案 | 状态 |
|----------|----------|------|
| 多 Agent 并行协同 | 基于 multiAgentOrchestrator，四 Agent（控场/转写/决议/待办）并行订阅共享黑板 | 已实现基础框架 |
| RAG 知识检索（会前） | 调用 embedding 模型 + 向量数据库（Milvus/Pinecone），检索相关历史文件 | 框架已有，接入真实向量库即可 |
| 议程自动生成 | LLM 接收 RAG 检索结果 + 会议主题 Prompt，输出结构化 JSON | 已实现 mock，可替换真实模型 |
| 会议转写 | 接入 Whisper API（实时语音转文字） | 待接入 |
| 决议/待办意图识别 | LLM + few-shot prompt，识别"决定""请张三"等关键词模式 | 已实现 mock |
| 会后自动派单 | 派单结果写入 meetingWorkItemStore，触发通知中心 | 已实现 |
| 任务催办 | 定时任务扫描到期待办，触发钉钉/企微/邮件通知 | 待接入 |

### 亮点二 · 睿鉴风控

| 技术模块 | 实现方案 | 状态 |
|----------|----------|------|
| 七段指纹 | 中间件拦截 RAG/Prompt/LLM/Output/Dispatch/Confirm 每步写日志，含 requestId 串联 | 已实现框架 |
| 政策规则引擎 | 数据库存储监管规则，支持热更新，命中时触发 block | 已实现 mock 规则 |
| 合规报告检测 | 文本 → 规则匹配 → 风险评分 → 输出阻断/警告/通过 | 已实现 |
| AI 改写建议 | LLM 接收违规原文 + 法规引用，输出合规替代表达 | 待实现 |
| 审计日志 | 结构化日志写入 MySQL/ElasticSearch，支持多维检索 | 已实现 mock |
| 双人复核 | 高风险操作写锁，requester + reviewer 双签 | 待实现 |
